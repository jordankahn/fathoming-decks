# The Fathoming — Decks

Presentation decks for The Fathoming, served with GitHub Pages.

| Deck | Folder |
|---|---|
| Sinful Shadows expansion release event | [`sinful-shadows/`](sinful-shadows/) |

Each deck is plain HTML, CSS and JavaScript with its images and fonts alongside it, so it also runs offline: open the folder's `index.html` in a browser.

## Controls

| Key | Action |
|---|---|
| → / Space | Next step or slide |
| ← | Back |
| F | Fullscreen |
| O | Slide overview |
| N | Speaker notes |
| B / Esc | Leave a Sin slide (Sinful Shadows deck) |

Click any card to enlarge it. On the last slide of the Sinful Shadows deck, click a Shrine to open that Sin.
